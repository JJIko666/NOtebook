# Noteverse — Your Knowledge. Your Space.

Офлайн-приложение для красивых конспектов: готовые шаблоны, рисование поверх страницы,
12 текстовых эффектов, звуки, проверка письма, экспорт, просмотр PDF без интернета.

## Как запустить в VS Code

1. Откройте папку проекта в VS Code (`File → Open Folder`).
2. Установите расширение **Live Server** (Ritwick Dey).
3. Правый клик на `index.html` → **Open with Live Server**.

Без расширения: в терминале VS Code выполните `npx serve . -l 5173` или `python -m http.server 5173`
и откройте `http://localhost:5173`.

> Двойной клик по `index.html` (адрес `file://`) работает не полностью: браузер не даёт
> загрузить PDF.js и service worker. Нужен локальный сервер, как выше.

## Структура

```
index.html            страница
css/style.css         основной дизайн (палитры v1.3, светлая/тёмная тема)
css/extra.css         холст эффектов, блоки шаблонов, галерея, просмотр PDF, печать
js/app.js             хранилище (IndexedDB), редактор, рисование, звук, проверка письма, настройки
js/fx.js              движок текстовых эффектов (частицы, физика, 12 эффектов, панель FX)
js/templates.js       галерея из 15 шаблонов
js/pdfview.js         просмотр PDF (PDF.js, всё локально)
js/init.js            запуск и перенос старых данных
js/pwa.js, sw.js      офлайн-режим (service worker)
vendor/pdfjs/         pdf.min.mjs и pdf.worker.min.mjs (локальная копия PDF.js)
tests/                автоматические проверки (Playwright)
```

Скрипты подключены обычными тегами `<script>` в таком порядке: app → fx → templates → pdfview → init → pwa.
Порядок важен: они делят общие переменные.

## Офлайн

Откройте приложение один раз с интернетом: service worker сохранит все файлы.
После этого оно запускается и без сети. Заметки хранятся в IndexedDB на этом устройстве и в этом браузере.
Резервная копия: ⚙ → «Экспорт копии» / «Импорт копии» (JSON).

Шрифты подключаются с Google Fonts. Без интернета браузер использует системные шрифты.
Чтобы шрифты тоже были локальными, скачайте файлы `.woff2` в папку `vendor/fonts/`
и подключите их через `@font-face` в `css/style.css`.

## PDF

- **Открыть PDF**: кнопка «📄 PDF» — страницы, масштаб, переход по номеру, поиск с подсветкой. Работает без интернета.
- **Сохранить заметку как PDF**: «Скачать → PDF» открывает системное окно печати, выберите «Сохранить как PDF».
  Это векторный PDF с выделяемым текстом. Эффекты и анимация в PDF не попадают, текст идёт обычным.

Чтобы обновить PDF.js: `npm i pdfjs-dist`, затем скопируйте `build/pdf.min.mjs` и
`build/pdf.worker.min.mjs` из `node_modules/pdfjs-dist` в `vendor/pdfjs/`.

## Эффекты текста

Выделите слово или предложение (или поставьте курсор в абзац) → **✨ FX** → выберите эффект → **Применить**.
Текст остаётся настоящим и редактируемым. Настройки эффекта хранятся отдельно от текста.
Частицы рисуются на странице позади букв и не выходят за границы своего слова.
В панели можно выбрать качество (Низкое / Среднее / Высокое / Авто) или отключить все эффекты.
Эффекты уважают системную настройку «уменьшить движение».

## Известные ограничения

- Данные лежат только на этом устройстве. Облака и синхронизации в этой версии нет (по плану — следующая фаза).
- Из 60 дизайнов реализовано 12 стилей и все 20 палитр.
- Ещё не сделаны: Knowledge Map, голос в текст, OCR, режим учёбы и карточки, календарь, история версий, совместная работа, экспорт в DOCX.
- Проверка письма: подсветка повторов и ошибок пунктуации, орфография через браузер. Полноценной проверки грамматики нет.
- Тесты запускались только в Chromium. Safari, Firefox, касание и стилус не проверялись.
